# Voiceflow — Installation

1. **Voiceflow-beta.dmg öffnen** und Voiceflow → Programme ziehen.

2. **Erster Start:** Rechtsklick auf Voiceflow.app → „Öffnen" → im Dialog nochmals „Öffnen".
   (Einmalig nötig — macOS Gatekeeper bei Beta-Builds.)
   Alternativ im Terminal: `xattr -cr /Applications/Voiceflow.app`

3. **OpenAI API-Key eintragen:** Beim ersten Start öffnet sich das Setup-Fenster.
   Key erstellen auf https://platform.openai.com/api-keys, einfügen, fertig.
   Der Key bleibt im Schlüsselbund dieses Macs. Kosten: ~0.3 Rappen pro Diktatminute.

4. **Shortcuts festlegen:** Menüleisten-Icon → Einstellungen → drei Shortcuts
   für Private / Business / Calm vergeben (z. B. ⌥1, ⌥2, ⌥3) → Speichern.

5. **Mikrofon erlauben:** System-Dialog beim ersten Diktat bestätigen.

6. **Bedienungshilfen erlauben** (für direktes Einfügen):
   Systemeinstellungen → Datenschutz & Sicherheit → Bedienungshilfen → Voiceflow aktivieren.
   Ohne diese Berechtigung landet der Text in der Zwischenablage (⌘V zum Einfügen).

## Benutzung

- Shortcut drücken → sprechen → gleichen Shortcut nochmals drücken.
- Der Text erscheint im aktiven Textfeld — bereinigt im gewählten Ton-Modus:
  - **Private** — leichte Korrektur, dein Wortlaut bleibt
  - **Business** — professioneller Geschäftston
  - **Calm** — deeskaliert, sachlich statt emotional
- Verlauf: Rechtsklick auf das Menüleisten-Icon → „Verlauf öffnen".
